# NINA.Bot Privacy Policy

Last updated: 18 June 2026

NINA.Bot is a Discord bot used by the N.I.N.A. (Nighttime Imaging 'N' Astronomy)
community to provide support automation, troubleshooting utilities, and server
workflow assistance.

This policy explains what data NINA.Bot processes, why it processes that data,
and how users can request access or deletion.

## Data NINA.Bot Processes

NINA.Bot may process the following Discord data when users interact in servers
where the bot is installed:

- Discord user identifiers, usernames, and message metadata needed to respond to
  commands and Discord events.
- Message content when required for legacy text commands and support automation.
- Message attachment metadata and uploaded autofocus report files when users post
  N.I.N.A. autofocus JSON reports for analysis.
- Discord reaction events used for server workflows such as assigning a member
  role after a user reacts to the welcome message.
- Operational logs needed to run, debug, and maintain the bot.

## How NINA.Bot Uses Data

NINA.Bot uses Discord data only to provide community support and server utility
features, including:

- Responding to support commands with documentation links and troubleshooting
  guidance.
- Processing uploaded N.I.N.A. autofocus JSON reports to validate the report,
  analyze autofocus data, render a diagnostic graph, and post the result back in
  Discord.
- Supporting welcome and role-assignment workflows based on user reactions.
- Maintaining and debugging the bot service.

NINA.Bot does not use message content, attachments, or user data for advertising,
profiling, resale, or broad analytics.

## Message Content and Attachments

NINA.Bot uses Discord's Message Content privileged intent for support workflows
that require access to normal Discord messages or attachments.

For autofocus report analysis, uploaded JSON attachments are downloaded and
processed to generate a diagnostic response in Discord. The report data is used
only for that support workflow.

Legacy text commands may require reading message content to determine whether a
message invokes a bot command. Where possible, command-style interactions may be
migrated to Discord slash commands over time.

## Data Retention

NINA.Bot does not intentionally maintain a long-term archive of Discord message
content.

Autofocus report attachments are processed to generate the bot response and are
not retained by the bot as a permanent data store.

Operational logs may be retained for maintenance, debugging, abuse prevention,
and service reliability. Log retention depends on the hosting environment and is
kept only as long as reasonably needed for those purposes.

## Data Sharing

NINA.Bot does not sell user data.

Data may be processed by infrastructure providers required to host, operate, or
monitor the bot. Data may also be disclosed if required to comply with applicable
law, legal process, or Discord platform requirements.

## User Choices

Users can avoid optional bot processing by not invoking bot commands and not
uploading autofocus report attachments for analysis.

Some server workflow processing, such as reaction-based role assignment, applies
when a user interacts with the relevant Discord message or server workflow.

## Access and Deletion Requests

Users may request access to or deletion of bot-related data by contacting the
N.I.N.A. Discord server administrators or project maintainers.

Contact: https://nighttime-imaging.eu/

Please include enough information to identify the relevant Discord account and
server interaction, such as your Discord user ID and the approximate date of the
interaction.

## Changes to This Policy

This policy may be updated as NINA.Bot changes. Updates will be published in
this file.
